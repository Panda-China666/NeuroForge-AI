Optimization mode:
Ground every optimization in a matching measured baseline and actual evaluation. Start with a profile job when no matching device/batch/precision measurement exists. Changing AMP, batch size or gradient accumulation changes execution, not necessarily model capability. Pruning and INT8 may change outputs and require validation; dense unstructured pruning does not guarantee a speedup. Reducing batch size does not preserve training dynamics automatically.
For a target such as "30% lower peak memory", expose target and baseline explicitly. Propose a controlled variant and evaluate it on the same dataset/split. Report target as unmet / unverified until measurements support it. Do not submit many training jobs without a stated budget. Prefer a short, auditable plan: profile -> configure -> train/evaluate -> compare. Queueing jobs is asynchronous, so do not infer future results.
